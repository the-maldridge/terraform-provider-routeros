# routeros_system_keymat_provider (Resource)
Key material providers, which either derive keys locally with HKDF or take keys from a QKD device. Available in RouterOS starting from version 7.24.

## Example Usage
```terraform
resource "routeros_system_keymat_provider" "hkdf" {
  name        = "hkdf1"
  type        = "hkdf"
  key_size    = 128
  hkdf_hash   = "sha256"
  hkdf_secret = "00112233445566778899aabbccddeeff"
}

resource "routeros_system_keymat_provider" "qkd" {
  name            = "qkd1"
  type            = "qkd"
  key_size        = 128
  qkd_address     = "192.168.88.2"
  qkd_kme_id      = "kme1"
  qkd_peer_sae_id = "sae1"
  qkd_certificate = "none"
  qkd_cache_size  = 8
}
```

## Schema

### Required

- `name` (String) Name of the key material provider.
- `type` (String) The way key material is generated: `qkd` takes keys from a QKD device, `hkdf` derives keys locally with HKDF.

### Optional

- `disabled` (Boolean)
- `hkdf_hash` (String) Hash algorithm used for the HKDF key derivation.
- `hkdf_secret` (String, Sensitive) A hexadecimal string value used as the input keying material for the HKDF key derivation.
- `key_size` (Number) The size of the generated key material in bits.
- `qkd_address` (String) The address of the KME device.
- `qkd_cache_size` (Number) The number of unused keys to keep in cache.
- `qkd_certificate` (String) The certificate used to authenticate against the KME device, this also specifies your SAE ID.
- `qkd_kme_id` (String) The KME ID, it should match the KME ID in the received TLS certificate of the KME device.
- `qkd_peer_sae_id` (String) The peer (master or slave) SAE ID.

### Read-Only

- `id` (String) The ID of this resource.
- `qkd_cache_state` (Number) The number of currently unused keys in cache.
- `qkd_total_keys_received` (Number) The total number of keys received from the KME device.
